# Exploration e cozinha

Um projeto de jogo 3D desenvolvido na **Godot Engine 4.7.2**, focado em exploração, coleta de recursos e culinária.

## Sobre o projeto

Este projeto tem como objetivo explorar mecânicas de exploração em um ambiente 3D com câmera em perspectiva *top-down / high-angle*, combinando coleta de recursos e preparação de alimentos.

O desenvolvimento é experimental e voltado ao aprendizado e à implementação gradual de sistemas de gameplay.

## Funcionalidades implementadas

- **Movimentação em 3D:** movimentação do personagem utilizando WASD.
- **Câmera dinâmica:** câmera em ângulo elevado, com enquadramento adaptável ao ambiente.
- **Coleta de madeira:** possibilidade de coletar recursos espalhados pelo mapa.
- **Corte de árvores:** árvores podem ser derrubadas após receber uma quantidade determinada de golpes, gerando madeira coletável.
- **Sistema de inventário:** barra rápida com exibição da quantidade de madeira e comida.
- **Sistema de culinária:** utilização de madeira para iniciar o cozimento de alimentos.
- **Barra de progresso:** indicador visual do tempo necessário para concluir o cozimento.
- **Interação com objetos:** sistemas de interação para coleta de recursos e utilização de estações de cozinha.
- **Interface personalizável:** barra rápida que pode ser exibida ou ocultada com a tecla Tab.

## Tecnologias utilizadas

- [Godot Engine](https://godotengine.org/) 4.7.2
- GDScript
- Godot 3D
- Sistema de física e colisões da Godot
- Interface criada com os nós de UI da Godot

## Controles

| Tecla / Botão | Ação |
|---|---|
| W, A, S, D | Movimentar o personagem |
| Botão esquerdo do mouse | Atacar árvores |
| E | Coletar madeira ou interagir com o fogão |
| Tab | Exibir ou ocultar a barra rápida |

## Objetivo do projeto

Este projeto serve como uma oportunidade para estudar e praticar:

- Programação de gameplay com GDScript.
- Sistemas de interação entre objetos e jogador.
- Gerenciamento de recursos e inventário.
- Criação de interfaces de usuário.
- Manipulação de câmeras e enquadramento em ambientes 3D.
- Organização e reutilização de cenas e scripts.
